# ⚡ REXX Code Library

**IBM z/OS | TSO/E | Mainframe Development**

A collection of REXX programs, practical examples, and reusable code for mainframe development.

## 📚 Programs

### [Count PDS Members by Prefix](./count-pds-members-by-prefix/)

Counts the members of a partitioned data set (PDS) whose names start with a specified prefix.

**Language:** REXX  
**Platform:** IBM z/OS


### [List DASD Usage](./list-dasd-usage/)

Displays DASD volume serials and usage percentages using the MXI REXX interface.

**Language:** REXX  
**Platform:** IBM z/OS


### [DB2 REXX Stored Procedure](./rexx-stored-procedure/)

Demonstrates how to create and configure DB2 stored procedures using REXX on IBM z/OS, including WLM setup and JCL submission through an internal reader.

**Language:** REXX  
**Platform:** IBM z/OS


### [Count Dataset Lines](./count-dataset-lines/)

Counts the number of records in a sequential data set or a PDS/PDSE member using the REXX EXECIO command.

**Language:** REXX  
**Platform:** IBM z/OS
