**IBM z/OS | COBOL | DB2 for z/OS | Mainframe Development**

A collection of COBOL programs, practical examples, and reusable code for mainframe development.

## 📚 Programs

### [DB2 Table Replication](https://github.com/lvlehrdadT/mainframe-code-library/tree/main/COBOL/db2-table-replication)

Replicates records from a source DB2 table to a target DB2 table using COBOL and Embedded SQL. Demonstrates cursor processing, batch operations, transaction management, and error handling.

**Language:** COBOL  
**Platform:** IBM z/OS / DB2 for z/OS

### [ICSF 3DES Encryption and Decryption](https://github.com/lvlehrdadT/mainframe-code-library/tree/main/COBOL/cobol-icsf-3des-encryption)

Demonstrates 3DES encryption and decryption using IBM ICSF callable services (CSNBSYE and CSNBSYD), with DB2 Embedded SQL integration and hexadecimal representation of encrypted data.

**Language:** COBOL  
**Platform:** IBM z/OS / DB2 for z/OS / IBM ICSF
